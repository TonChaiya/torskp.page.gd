# บันทึกสถานะปัจจุบัน — v1.3.0

**สถานะล่าสุด 25 พฤศจิกายน 2569 (ปิดงาน v1.3.0):** ผู้ใช้ยืนยันว่า Dev ใช้งานได้ และอัปโหลดขึ้น InfinityFree ใช้งานจริงได้หมดแล้ว (12:56 น. ICT). กำหนด v1.3.0 เป็น stable maintenance baseline ตามการยืนยันของผู้ใช้; ไม่ใช่ผลรับรอง independent UAT หรือ security audit. ข้อความ Candidate/รอ Push/รอ Production ในเนื้อหาเดิมด้านล่างเป็นบันทึกตามเวลาที่เขียน ไม่ใช่งานค้างปัจจุบัน. ข้อกำหนดทางเทคนิคและข้อจำกัดการทดสอบเดิมยังคงมีผล.

อ่าน [สถานะ canonical](../../docs/PROJECT_STATUS.md) สำหรับงานคงเหลือและขอบเขตหลักฐาน.

### สถานะไฟล์แม่แบบปัจจุบัน
ตรวจ tree รุ่น v1.3.0 `f30c93cf`: มี `principle_approval_memo.docx`, `committee_scope_invitation.docx`, `scope_price_approval_memo.docx`. ไม่มีไฟล์ `meeting_report.docx` หรือ `tor_company_purchase.docx` ใน tree; ไม่ได้หมายความว่าฟังก์ชันส่งออกสองหัวข้อนั้นยังไม่เสร็จ (มีเส้นทาง export เดิมตาม [WORD_EXPORT](../../docs/WORD_EXPORT.md)). ตารางเดิมด้านล่างเป็นแผนแม่แบบในอดีต ไม่ใช่คำสั่งให้สร้าง template เพิ่ม. ผู้ใช้ยืนยันเว็บใช้งานจริงได้; คงแม่แบบและกลไก Word V4 เดิม. ไม่ทดสอบ rendering หรือเปลี่ยน binary ในรอบปิดเอกสาร.

# DOCX templates

แม่แบบในโฟลเดอร์นี้เป็น DOCX แบบ native และใช้ PDF/หน้าพิมพ์ของระบบเป็นต้นฉบับด้านการจัดหน้า

| เอกสาร | แม่แบบ | สถานะ |
|---|---|---|
| ขออนุมัติในหลักการ | `principle_approval_memo.docx` | ใช้งานและผ่าน QA |
| เชิญกรรมการ/ระเบียบวาระ | `committee_scope_invitation.docx` | ใช้งานและผ่าน QA |
| รายงานการประชุม | `meeting_report.docx` | รอดำเนินการ |
| TOR จัดซื้อยา | `tor_company_purchase.docx` | รอดำเนินการ |

สร้างแม่แบบใหม่ด้วย `php tools/build_docx_templates.php` ระบบดาวน์โหลดจะคัดลอกแม่แบบไปยังไฟล์ชั่วคราว เติมข้อมูล แล้วลบไฟล์ชั่วคราวใน `finally` โดยไม่เขียนทับแม่แบบต้นฉบับ
