# TH SarabunIT๙

ไฟล์ฟอนต์ในโฟลเดอร์นี้ใช้สำหรับฝังลงในเอกสาร DOCX ที่ระบบสร้าง เพื่อให้เอกสารยังคงรูปแบบเดิมเมื่อเปิดบนเครื่องที่ไม่ได้ติดตั้งฟอนต์

- `THSarabunIT9-Regular.ttf`
- `THSarabunIT9-Bold.ttf`
- `THSarabunIT9-Italic.ttf`
- `THSarabunIT9-BoldItalic.ttf`

ชื่อฟอนต์ภายในไฟล์คือ `TH SarabunIT๙` และค่า `fsType` ของทั้งสี่ไฟล์เป็น `0` ซึ่งอนุญาตการฝังฟอนต์
